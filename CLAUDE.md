# Strata: tài liệu kỹ thuật và sử dụng cho agent

Strata là công cụ quản lý task, issue, tài liệu và C4. Luật và quy trình agent dùng chung nằm trong `agent/`: [`agent/BOOTSTRAP.md`](agent/BOOTSTRAP.md), [`agent/HIEN_PHAP.md`](agent/HIEN_PHAP.md). Sổ tay dùng công cụ là [`agent/skills/strata/SKILL.md`](agent/skills/strata/SKILL.md).

## Tài liệu tham chiếu

- `docs/architect/ARCHITECTURE.md`: cấu trúc code, nguyên tắc.
- Vẽ/sửa C4 hoặc flow: `docs/AGENT_C4.md`.
- Viết tài liệu: `docs/architect/doc-format.yaml`.

## Kiến trúc và kiểm chứng

1. **Ghi qua service có kiểm tra và audit.** CLI/MCP là đường ghi chung. Viewer và server HTTP chỉ đọc, SÁU NGOẠI LỆ: `POST /api/c4/edit` (tab Architect): sửa thư mục YAML C4 của project qua service (kiểm như `c4 validate`, ghi vào thư mục, rồi import có audit); `POST /api/project` (op `add|edit|delete` từ sidebar, qua service có audit; `delete` là xoá cứng dòng trong DB, không đụng file, bắt buộc gõ lại id để xác nhận và tự sao lưu DB trước); `POST /api/item` (op `add|edit|delete|dep_add|dep_rm` trên task/issue, qua service có audit; sửa được mọi trường: title, body, status, priority, deps, spec goal/acceptance/verify/scope; `delete` là xoá cứng, có audit); và `POST /api/chat` (chat AI, op `start|turn|settings|decide|cancel|close|login|cancel_login`; không ghi DB/audit, chỉ điều khiển phiên agent cục bộ: Claude Code (mặc định, `strata/chat_claude.py`, chạy `claude -p` bằng đăng nhập subscription có sẵn trên máy, không chuyển biến API key nào vào tiến trình con) hoặc Codex; `login` với `provider: claude` lấy link đăng nhập rồi nhận `code` người dùng dán lại; `start` nhận project id đã đăng ký trong DB, không nhận đường dẫn từ trình duyệt; `start` tạo một git worktree riêng trên đĩa dưới `.strata-worktrees/` cạnh project, và phiên chạy với cwd là worktree đó; không có guard đường dẫn riêng, ranh giới là duyệt từng hành động qua `decide` + cwd worktree (Codex thêm sandbox `read-only`; Claude chạy theo chế độ quyền người dùng chọn, mặc định `auto`, chỉ trong danh sách `auto|manual|acceptEdits|plan` của `strata/claude_models.py` (không có `bypassPermissions`/`dontAsk`), mọi yêu cầu quyền Claude Code còn hỏi đi qua `decide`; `settings` đổi model/effort/chế độ giữa hai lượt bằng cách dừng tiến trình rảnh và `--resume` cùng phiên ở lượt sau; model và effort chỉ nhận giá trị trong cùng file đó); khoá API chỉ lấy từ môi trường server, chỉ vào env của tiến trình codex app-server (`OPENAI_API_KEY`), bị `shell_environment_policy` lọc khỏi tiến trình con chạy lệnh/tool, và không bao giờ tới trình duyệt). Kèm 3 route đọc `GET /api/chat/events`, `GET /api/chat/auth`, `GET /api/chat/diff`: bắt buộc `X-Strata-Token` và kiểm Host, không ghi DB/audit (`auth` chạy codex hoặc `claude auth status`, `diff` chạy git). Hai ngoại lệ còn lại phục vụ dock ở đáy viewer (`viewer/dock.js`): `POST /api/term` (op `open|input|resize|close|list`: shell thật trên server qua PTY, `strata/term.py`; không ghi DB/audit; có công tắc riêng `allow_terminal`, mặc định bằng `allow_edit`, bật cho mọi địa chỉ bằng `serve --allow-terminal`; kèm route đọc `GET /api/term/read`) và `POST /api/agent` (op `auto|settings|run|stop`: agent chạy task, `strata/agents.py`; mọi đổi trạng thái task đi qua service có audit; kèm 2 route đọc `GET /api/agents`, `GET /api/agent/log`). Ba route đọc này bắt buộc `X-Strata-Token`. Mọi route ghi (cả sáu) phải qua: cờ `allow_edit` (mặc định chỉ khi bind loopback), header `X-Strata-Edit: 1`, token ngẫu nhiên mỗi lần khởi động gửi trong header `X-Strata-Token`, cộng kiểm Origin/Host sẵn có. Không có route POST/PUT/DELETE nào khác.
   - Bảng `doc` là chỉ mục dẫn xuất từ file; server autoscan được làm mới nó, không ghi audit.
   - Bản đồ C4 là thư mục layered (`docs/c4`); sửa file rồi `c4 import`; sửa từ viewer chỉ đi qua route `POST /api/c4/edit` nói trên. SQLite chỉ là read model của thư mục đó.
2. **Không phụ thuộc nặng.** Python stdlib + PyYAML; JS thuần, không build, không CDN.
   - Ngoại lệ có phạm vi: `tools/gitnexus` là công cụ Node vendored cho agent, chỉ gọi qua CLI/subprocess, code Strata không bao giờ import nó; lõi vẫn là Python stdlib + PyYAML và JS thuần.
3. **Tài liệu chỉ nội dung.** Agent viết YAML theo `doc-format.yaml`; không tự viết HTML/CSS/JS cho tài liệu. Framework lo trình bày.
4. **Kiểm chứng thay đổi ứng dụng: chạy test, restart, mở viewer.** `systemctl --user restart strata`, cổng 8740. Sửa CSS/JS thì nhắc Ctrl+Shift+R.
5. Test: `venv/bin/python -m pytest -q` (venv ở gốc repo). Báo đúng số pass/fail.

## Agent chạy task

Project bật auto-run (Agents ở dock, mặc định tắt) thì task `approved` đủ điều kiện được agent tự nhận. Runner (`strata/agents.py`) làm các bước chạm board và remote, agent chỉ làm phần code: claim (`doing`, owner `agent:claude`) → `git fetch origin` → worktree `.strata-worktrees/<project>/<action>/<scope>/<work>_t<id>` trên nhánh cùng tên, cắt từ nhánh mặc định của origin → Claude Code headless → kiểm → push đúng nhánh đó → `review` kèm báo cáo. Task cùng project chỉ chạy song song khi `scope.touch` không giao nhau. Ba lớp giới hạn thẩm quyền: hook `agent/hooks/agent_guard.py` (mọi tool call); sandbox bubblewrap khi máy có (chỉ ghi được worktree và kho git, không thấy đăng nhập GitHub); và chỉ runner push, sau khi kiểm nhánh, file thay đổi nằm trong `scope.touch`, CI chỉ đổi khi task có `ci_change_approved: true`, cấu hình git và các ref không liên quan không đổi. Không bao giờ push nhánh mặc định, không force. Tên nhánh, quy trình CI tạo PR và các giới hạn remote được ghi trong [`agent/skills/strata-task-pipeline/SKILL.md`](agent/skills/strata-task-pipeline/SKILL.md).

Viewer hiển thị Agents ở dock dưới và terminal AI chat ở khung phải (`viewer/dock.js`). `strata/agent_sessions.py` quét tiến trình Claude/Codex của user hiện tại; process trong PTY Strata dùng lại đúng terminal khi mở thẻ, process ngoài chỉ hiện thông tin. Agent chạy headless hiện log. Task của một CLI được ghép theo worktree của run đã biết. Quan hệ cha/con lấy từ cây process hoặc hook `SubagentStart`/`SubagentStop` cho subagent nội bộ; subagent nội bộ dùng chung terminal hoặc log của cha.

## Thư mục `agent/`

`agent/` chứa luật, vai agent, quy trình, hook và skill dưới dạng file thật (đã gộp từ Endo); đây là nguồn chuẩn và nơi sửa chính sách. [`agent/skills/strata/SKILL.md`](agent/skills/strata/SKILL.md) là sổ tay công cụ. `agent/skills/schematic/` là skill bên thứ ba, cố ý nằm ngoài git.
